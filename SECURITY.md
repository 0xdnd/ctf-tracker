# Security Policy

## Supported versions

Only the latest release of ZeroBox receives security fixes. Please update before reporting.

## Reporting a vulnerability

Use GitHub private vulnerability reporting for this repository:
<https://github.com/0xdnd/ctf-tracker/security/advisories/new>

Please do not open a public issue for a suspected vulnerability. Include the affected version, steps to reproduce, and the impact you observed.

## Response times

- Acknowledgement within 7 days of your report.
- We will keep you updated while we investigate and agree on a disclosure timeline with you before anything is published.

## Scope

ZeroBox is local-first: there is no backend and no user accounts, and data stays in your browser or on your machine. In scope are the client web app and the Tauri desktop build. Third-party services and sites the app links to are out of scope.
